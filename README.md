# SVOI — Street Action Community

Адаптивная главная страница на React + Vite.

## Запуск локально
- `npm install`
- `npm run dev`

## Сборка
- `npm run build`
- папка результата: `dist`

## Cloudflare Pages
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`

В текущей версии бегущий персонаж — стилизованная CSS-заглушка. Для кинематографичного реалистичного эффекта подключим видео спортсмена, управляемое прокруткой.
